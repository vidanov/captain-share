    Captain Share

    Your team keeps agent skills in one Git library. Captain Share links them into every agent and project on this machine, and shares yours back. It runs only on this computer; nothing leaves it except your own Git pushes.

    Watch the one-minute tour Version __APP_VERSION__ · MIT license · macOS and Linux

    Get

    Library shows what is new since you last looked. Get links a skill globally, for all your projects, or only in one project.

    Share

    Share copies a skill you made, or one from a zip, into the library, commits it with your note, and pushes. Teammates run captain-share get NAME.

    Stay in control

    Every change is shown before it happens. Nothing is deleted: removed files go to the Archive and can be restored.

    Words used here

    Library
    A Git repository where your team keeps shared assets, for example team-skills. You clone it once; Update library pulls what others pushed.
    Asset
    Anything a library holds: a skill (a folder with SKILL.md), an agent (a .json file), a prompt or steering file (.md), or a Kiro power.
    Agent you use
    The coding assistant that reads the asset: Kiro (IDE and CLI), Claude Code, Codex, or Copilot. Settings chooses which ones get links.
    Get · Remove
    Get links an asset from the library into your agents' folders. Remove takes the link away and keeps a copy in the Archive.
    Global · Only in this project
    Where a Get applies. Global installs into your home folder (~/.kiro, ~/.claude, …), so every project sees it; Only in this project installs into the project this window opened on.
    Link · original
    Your agents' folders hold links, not copies. The one original stays in the library, so a library update reaches every project at once.
    Share
    Copy a skill you made or edited into the library, commit it with a note, and push it for the team.
    Starter set · profile
    A list of assets a library suggests together. The starter set is the profile named starter, kept in the library as profiles/starter.manifest; first setup offers it.
    Folder above
    Under Where installed: a folder that holds several projects. What you choose there applies to every project inside it.
    Archive
    Where removed or replaced files go. Nothing is deleted; you can restore from it.
    Layout
    How a library is arranged: assets under ip/skills, ip/agents, … or directly under skills, agents, …. It is detected for you.

    Where files go

    Skills
    .kiro/skills · .claude/skills · .agents/skills (Codex)
    Agents, prompts, steering
    .kiro/agents · .kiro/prompts · .kiro/steering
    Kiro powers
    installed globally by kiro-cli
    Copilot
    .github/ instructions and prompts

    In a project folder, or in your home folder when you get something globally. Each is a link to the one original in the library.

    Start from a terminal 
    captain-share serve --open
captain-share get NAME
captain-share --help

    The window works for the folder you start it in, the folders above it, Global (your home folder), and projects you register.

    When something needs attention
    • Connection expired: open the complete URL printed by the running server.
    • Missing library: check the local checkout path and selected layout.
    • Pull unavailable: commit or stash local changes in your Git client.
    • Authentication failed: verify repository access in your Git client; the web UI does not prompt for credentials.
    • Preview became stale: preview again after the files or configuration change.
    • Missing link: preview and apply to repair it. A replaced or retargeted link needs review.
    Settings files
    ~/.captain/sharing.json
    Your defaults, agents, and libraries for every project.
    .captain/sharing.json
    A folder's choices; safe to commit for your team.
    .captain/sharing.local.json
    This machine's checkout paths; kept out of Git.
